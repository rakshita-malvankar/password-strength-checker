# Password-Strength-Checker
A beginner Python project that check password strength of a password.
## Features
1.checks password length
2.checks uppercase and lowercase letter
3.checks number
4.checks special characters
5.Ask for a new password if the password is not strong
## Technologies Used
Python
## How it Works
The program checks five Password requirement and accept the password only when all requirements are satisfied.
## Example
Enter your Password:abc
Password is not strong
Enter your Password:Hello123!
Password strength strong
Password accepted
